# Eyebright

![Eyebright]({{ '/assets/herbs/eyebright.png' | relative_url }})

*Euphrasia officinalis*. Tiny white flowers with purple veins and a yellow spot, half-parasitic on grass; exaggerate it. Back to [Herbs](../herbs).
