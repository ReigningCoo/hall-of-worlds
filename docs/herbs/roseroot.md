# Roseroot

![Roseroot]({{ '/assets/herbs/roseroot.png' | relative_url }})

*Rhodiola rosea*. Stout stems of blue-green fleshy leaves topped by flat yellow flower heads; clumps among rocks. The cut root smells of roses. Back to [Herbs](../herbs).

| | |
| - | - |
| Rarity | Rare |
| Grows in | Tundra, Boreal forest |
| Warmth | Lands whose year averages −8 to 6 °C |
| Part used | Root |
| Weight | 60 g each |

| Growth | Very slow: full grown in 16 days of game time |
