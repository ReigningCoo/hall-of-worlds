# Cinnamon

![Cinnamon]({{ '/assets/herbs/cinnamon.png' | relative_url }})

*Cinnamomum verum*. Shoots from a stump, glossy leaves flushed red when young. Back to [Herbs](../herbs).

| | |
| - | - |
| Rarity | Common |
| Grows in | Tropical rainforest |
| Warmth | Lands whose year averages 22 to 30 °C |
| Part used | Inner bark |
| Weight | 15 g each |
| Plant | Coppiced tree, about 300 cm tall and 200 cm across |
| Growth | Very slow: full grown in 16 days of game time |
| Picking | Coppiced: cut to the ground, it grows again from a shoot |
| Picked early | Yes, from stage 3 of 4, for 50% of a full picking |
