# Sundew

![Sundew]({{ '/assets/herbs/sundew.png' | relative_url }})

*Drosera rotundifolia*. Red rosettes of sticky dew-tipped hairs; exaggerate to knee height. Back to [Herbs](../herbs).

| | |
| - | - |
| Rarity | Uncommon |
| Grows in | Tundra, Boreal forest; marshes too, once the world has them |
| Warmth | Lands whose year averages −6 to 12 °C |
| Part used | Whole plant |
| Weight | 10 g each |
| Plant | Carnivorous perennial, about 45 cm tall and 40 cm across |
| Growth | Slow: full grown in 8 days of game time |
| Picking | Dug up: nothing grows there for a whole growth, then it starts again from a shoot |
| Picked early | Yes, from stage 3 of 4, for 50% of a full picking |
