# Angelica

![Angelica]({{ '/assets/herbs/angelica.png' | relative_url }})

*Angelica archangelica*. Taller than a person: hollow purple-tinged stems, great round heads of green-white flowers. Back to [Herbs](../herbs).

| | |
| - | - |
| Rarity | Uncommon |
| Grows in | Tundra, Boreal forest, Seasonal forest; marshes too, once the world has them |
| Warmth | Lands whose year averages −6 to 10 °C |
| Part used | Root and stems |
| Weight | 100 g each |
| Plant | Biennial, about 200 cm tall and 100 cm across |
| Growth | Medium: full grown in 4 days of game time |
| Picking | Dug up: nothing grows there for a whole growth, then it starts again from a shoot |
