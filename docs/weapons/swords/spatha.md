# Spatha

![Spatha]({{ '/assets/weapons/spatha.png' | relative_url }})

A long, straight blade with two edges, for cutting. One of the [swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 60 to 75 cm |
| Handle | 18 to 20 cm |
| Hands | One hand |
| Edges | Two edges |
| Curve | Straight |
| Guard | Mostly no guard; some a cross guard |
| Weight | About 1.0 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 4 to 1 × 5 cells |
