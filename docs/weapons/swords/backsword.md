# Backsword

![Backsword]({{ '/assets/weapons/backsword.png' | relative_url }})

A straight blade with one edge and a guard round the hand. One of the [swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 75 to 90 cm |
| Handle | 12 to 15 cm |
| Hands | One hand |
| Edges | One edge |
| Curve | Straight |
| Guard | Mostly a bow over the knuckles; some a basket |
| Weight | About 1.3 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 4 to 1 × 5 cells |
