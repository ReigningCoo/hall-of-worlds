# Rapier

![Rapier]({{ '/assets/weapons/rapier.png' | relative_url }})

A long, narrow blade for thrusting, with a cup or a bow guarding the hand. One of the [swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 100 to 130 cm |
| Handle | 12 to 15 cm |
| Hands | One hand |
| Edges | Two edges |
| Curve | Straight |
| Guard | Mostly a cup; some a bow over the knuckles |
| Weight | About 1.1 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 6 to 1 × 7 cells |
