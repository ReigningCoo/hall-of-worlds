# Sabre

![Sabre]({{ '/assets/weapons/sabre.png' | relative_url }})

A curved blade with one edge and a bow guarding the knuckles. One of the [swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 70 to 90 cm |
| Handle | 12 to 15 cm |
| Hands | One hand |
| Edges | One edge |
| Curve | Mostly slightly curved; some strongly curved |
| Guard | A bow over the knuckles |
| Weight | About 1.2 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 4 to 1 × 5 cells |
