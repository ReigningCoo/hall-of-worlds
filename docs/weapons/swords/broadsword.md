# Broadsword

![Broadsword]({{ '/assets/weapons/broadsword.png' | relative_url }})

A broad, straight blade with two edges and a basket guarding the hand. One of the [swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 75 to 90 cm |
| Handle | 12 to 15 cm |
| Hands | One hand |
| Edges | Two edges |
| Curve | Straight |
| Guard | A basket |
| Weight | About 1.9 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 4 to 1 × 5 cells |
