# Katana

![Katana]({{ '/assets/weapons/katana.png' | relative_url }})

A slightly curved blade with one edge, a round or square guard and a long grip for two hands. One of the [swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 60 to 80 cm |
| Handle | 25 to 30 cm |
| Hands | Two hands |
| Edges | One edge |
| Curve | Slightly curved |
| Guard | A disc |
| Weight | About 1.1 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 4 to 1 × 5 cells |
