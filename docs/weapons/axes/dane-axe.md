# Dane Axe

![Dane Axe]({{ '/assets/weapons/dane-axe.png' | relative_url }})

A long two-handed axe with a thin, crescent-shaped head. One of the [axes](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Edge of the head | 20 to 30 cm |
| Handle | 90 to 170 cm |
| Hands | Two hands |
| Edges | One edge |
| Weight | About 1.6 kg with a steel blade; its size and what it is made of change it |
| Takes up | 2 × 5 to 2 × 8 cells |
