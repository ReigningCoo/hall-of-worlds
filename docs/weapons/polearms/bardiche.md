# Bardiche

![Bardiche]({{ '/assets/weapons/bardiche.png' | relative_url }})

A very long axe blade, fixed to the pole at its lower end. One of the [polearms](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Edge of the head | 60 to 70 cm |
| Handle | 120 to 150 cm |
| Hands | Two hands |
| Edges | One edge |
| Weight | About 3.8 kg with a steel blade; its size and what it is made of change it |
| Takes up | 2 × 6 to 2 × 7 cells |
