# Claymore

![Claymore]({{ '/assets/weapons/claymore.png' | relative_url }})

A great two-handed sword whose guard slopes towards the blade. One of the [long swords](./). No two are quite alike: this is what one usually is.

| - | - |
| Blade | 100 to 115 cm |
| Handle | 30 to 36 cm |
| Hands | Two hands |
| Edges | Two edges |
| Curve | Straight |
| Guard | A cross guard |
| Weight | About 1.6 kg with a steel blade; its size and what it is made of change it |
