# Odachi

![Odachi]({{ '/assets/weapons/odachi.png' | relative_url }})

A very long, curved blade with one edge, for two hands. One of the [long swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 90 to 120 cm |
| Handle | 30 to 40 cm |
| Hands | Two hands |
| Edges | One edge |
| Curve | Slightly curved |
| Guard | A disc |
| Weight | About 1.6 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 6 to 1 × 8 cells |
