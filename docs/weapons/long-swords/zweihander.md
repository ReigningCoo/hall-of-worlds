# Zweihänder

![Zweihänder]({{ '/assets/weapons/zweihander.png' | relative_url }})

A huge two-handed sword with a blunt stretch above the guard and hooks to parry with. One of the [long swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 100 to 150 cm |
| Handle | 30 to 40 cm |
| Hands | Two hands |
| Edges | Two edges |
| Curve | Mostly straight; some wavy |
| Guard | A cross guard |
| Weight | About 1.9 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 7 to 1 × 8 cells |
