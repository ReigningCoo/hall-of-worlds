# Stiletto

![Stiletto]({{ '/assets/weapons/stiletto.png' | relative_url }})

A thin blade that is all point, for thrusting. One of the [daggers](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 20 to 30 cm |
| Handle | 9 to 11 cm |
| Hands | One hand |
| Edges | Only a point |
| Curve | Straight |
| Guard | Mostly a cross guard; some a disc; some no guard; some a bow over the knuckles; some a cup; some a basket |
| Weight | About 450 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 1 to 1 × 2 cells |
