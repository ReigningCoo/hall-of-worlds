# Misericorde

![Misericorde]({{ '/assets/weapons/misericorde.png' | relative_url }})

A thin, narrow blade for finding the gaps in armour. One of the [daggers](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 20 to 30 cm |
| Handle | 9 to 11 cm |
| Hands | One hand |
| Edges | Only a point |
| Curve | Straight |
| Guard | Mostly a cross guard; some no guard |
| Weight | About 450 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 1 to 1 × 2 cells |
