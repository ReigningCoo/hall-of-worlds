# Machete

![Machete]({{ '/assets/weapons/machete.png' | relative_url }})

A wide, heavy blade for chopping through growth, with no guard. One of the [knives](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 30 to 66 cm |
| Handle | 10 to 15 cm |
| Hands | One hand |
| Edges | One edge |
| Curve | Straight |
| Guard | No guard |
| Weight | About 1.0 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 2 to 1 × 4 cells |
