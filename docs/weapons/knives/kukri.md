# Kukri

![Kukri]({{ '/assets/weapons/kukri.png' | relative_url }})

A heavy blade bent forward, widening towards the tip, for chopping. One of the [knives](./). No two are quite alike: this is what one usually is.

| - | - |

| Hands | One hand |

| Curve | Bent forward |
| Guard | No guard |
| Weight | About 550 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 2 to 1 × 3 cells |
