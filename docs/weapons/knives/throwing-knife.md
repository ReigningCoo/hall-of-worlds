# Throwing Knife

![Throwing Knife]({{ '/assets/weapons/throwing-knife.png' | relative_url }})

A plain, balanced blade with two edges and hardly a handle, made to be thrown. One of the [knives](./). No two are quite alike: this is what one usually is.

| - | - |

| Handle | 8 to 12 cm |
| Hands | One hand |
| Edges | Two edges |
| Curve | Straight |
| Guard | No guard |
| Weight | About 300 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 1 to 1 × 2 cells |
