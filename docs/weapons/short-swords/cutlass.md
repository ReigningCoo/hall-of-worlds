# Cutlass

![Cutlass]({{ '/assets/weapons/cutlass.png' | relative_url }})

A short, slightly curved blade with a cup or shell guard. One of the [short swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 61 to 76 cm |
| Handle | 10 to 15 cm |
| Hands | One hand |
| Edges | One edge |
| Curve | Slightly curved |
| Guard | A cup |
| Weight | About 1.2 kg with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 4 cells |
