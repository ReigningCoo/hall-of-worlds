# Kopis

![Kopis]({{ '/assets/weapons/kopis.png' | relative_url }})

A heavy blade curved forward, for cutting blows. One of the [short swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 48 to 65 cm |
| Handle | 10 to 13 cm |
| Hands | One hand |
| Edges | One edge |
| Curve | Bent forward |
| Guard | Mostly a cross guard; some no guard |
| Weight | About 900 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 3 to 1 × 4 cells |
