# Gladius

![Gladius]({{ '/assets/weapons/gladius.png' | relative_url }})

A short, broad blade with two edges and a sharp point, for stabbing. One of the [short swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 45 to 68 cm |
| Handle | 13 to 17 cm |
| Hands | One hand |
| Edges | Two edges |
| Curve | Straight |
| Guard | Mostly no guard; some a disc |
| Weight | About 900 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 3 to 1 × 4 cells |
