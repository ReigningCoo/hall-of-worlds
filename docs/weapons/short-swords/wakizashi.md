# Wakizashi

![Wakizashi]({{ '/assets/weapons/wakizashi.png' | relative_url }})

A short curved blade with one edge, a round guard and a long grip. One of the [short swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 30 to 60 cm |
| Handle | 15 to 20 cm |
| Hands | One hand |
| Edges | One edge |
| Curve | Slightly curved |
| Guard | A disc |
| Weight | About 750 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 2 to 1 × 4 cells |
