# Falcata

![Falcata]({{ '/assets/weapons/falcata.png' | relative_url }})

A blade curved forward, with a hooked handle that guards the hand. One of the [short swords](./). No two are quite alike: this is what one usually is.

| | |
| - | - |
| Blade | 35 to 55 cm |
| Handle | 10 to 13 cm |
| Hands | One hand |
| Edges | One edge |
| Curve | Bent forward |
| Guard | Mostly a cross guard; some a disc; some no guard; some a bow over the knuckles; some a cup; some a basket |
| Weight | About 800 g with a steel blade; its size and what it is made of change it |
| Takes up | 1 × 2 to 1 × 3 cells |
