# Watermelon

![Watermelon]({{ '/assets/fruit/watermelon.png' | relative_url }}) ![Watermelon Slice]({{ '/assets/fruit/watermelon-slice.png' | relative_url }})

*Citrullus lanatus*. Back to [Fruit and nuts](../fruit).

| | |
| - | - |
| Kind | Fruit |
| Rarity | Uncommon |
| Grows in | Desert, Savanna; orchards too, where it is warm enough |
| Warmth | Lands whose year averages 18 to 30 °C |
| Comes as | A whole fruit, cut into 11 servings when you eat it |
| Weight | About 6 kg whole |
| Eating | A serving gives back some Health, until you move or are hurt |
| Effects | Raises Toughness a little for a while |
| Plant | A vine along the ground, about 35 cm tall and 2 m across |
| Growth | Medium: leaves, flowers and ripe fruit come round every 4 days of game time |
| Picking | One to three when ripe (each a whole fruit), more with Foraging and Orchards |
