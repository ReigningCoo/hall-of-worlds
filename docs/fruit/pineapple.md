| - | - |
| Kind | Fruit |
| Rarity | Uncommon |
| Grows in | Tropical rainforest, Savanna; orchards too, where it is warm enough |
| Warmth | Lands whose year averages 20 to 27 °C |
| Comes as | A whole fruit, cut into 6 servings when you eat it |
| Weight | About 2 kg whole |
| Eating | A serving gives back some Health, until you move or are hurt |
| Effects | None |
| Plant | A rosette of leaves, about 125 cm tall and 125 cm across |
