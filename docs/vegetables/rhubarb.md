![Rhubarb]({{ '/assets/vegetables/rhubarb.png' | relative_url }})

*Rheum rhabarbarum*. Back to [Vegetables, pulses and grains](../vegetables).

| | |
| - | - |
| Kind | Vegetable |
| Rarity | Very rare wild; farmed in fields |
| Grows in | Seasonal forest, Boreal forest; farms' fields there too |
| Part picked | The stalks |
| Comes as | One at a time |
| Weight | 100 g each |
| Eating | It gives back a little Health eaten raw, until you move or are hurt |
| Effects | Lowers Toughness a little for a while |
| Plant | A rosette of leaves, about 80 cm tall and 120 cm across |
| Growth | Very slow: full grown in 16 days of game time |
| Picking | One or two when full grown, more with Foraging and Crops |
| After picking | Coppiced: cut to the ground, it grows again from a shoot |
