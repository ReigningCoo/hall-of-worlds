*Brassica napus var. napobrassica*. Back to [Vegetables, pulses and grains](../vegetables).

| | |
| - | - |
| Kind | Vegetable |
| Rarity | Very rare wild; farmed in fields |
| Grows in | Boreal forest, Tundra; farms' fields there too |
| Part picked | The root |
| Comes as | A whole one, cut into 4 servings when you eat it |
| Weight | About 1 kg whole |
| Eating | A serving gives back some Health eaten raw, until you move or are hurt |
| Effects | None |
| Plant | Leaves over a swollen root, about 45 cm tall and 38 cm across |
| Growth | Medium: full grown in 4 days of game time |
| Picking | One to three when full grown, more with Foraging and Crops |
| After picking | Dug up: nothing grows there for a whole growth, then it starts again from a shoot |
