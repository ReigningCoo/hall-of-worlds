| - | - |
| Kind | Vegetable |
| Rarity | Rare wild; farmed in fields |
| Grows in | Tropical rainforest, Savanna; farms' fields there too |
| Part picked | The tuber |
| Comes as | A piece cut from a big one, cut again into 4 servings when you eat it |
| Weight | 300 g a piece |
| Eating | Seldom eaten raw: eaten as it is, it gives back no Health |
| Effects | Drains Health for a while |
| Plant | A climber up a pole, about 3 m tall and 80 cm across |
| Growth | Very slow: full grown in 16 days of game time |
| Picking | Two to four when full grown, more with Foraging and Crops |
