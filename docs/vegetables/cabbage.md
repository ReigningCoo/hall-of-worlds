*Brassica oleracea var. capitata*. Back to [Vegetables, pulses and grains](../vegetables).

| | |
| - | - |
| Kind | Vegetable |
| Rarity | Very rare wild; farmed in fields |
| Grows in | Boreal forest, Seasonal forest; farms' fields there too |
| Part picked | The leaves |
| Comes as | One at a time |
| Weight | 750 g each |
| Eating | It gives back some Health eaten raw, until you move or are hurt |
| Effects | Raises Toughness a little for a while |
| Plant | A rosette of leaves, about 50 cm tall and 65 cm across |
| Growth | Medium: full grown in 4 days of game time |
| Picking | One to three when full grown, more with Foraging and Crops |
| After picking | Dug up: nothing grows there for a whole growth, then it starts again from a shoot |
