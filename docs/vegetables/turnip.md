# Turnip

![Turnip]({{ '/assets/vegetables/turnip.png' | relative_url }})

*Brassica rapa subsp. rapa*. Back to [Vegetables, pulses and grains](../vegetables).

| | |
| - | - |
| Kind | Vegetable |
| Rarity | Uncommon wild; farmed in fields |
| Grows in | Boreal forest, Tundra, Seasonal forest; farms' fields there too |
| Part picked | The root |
| Comes as | One at a time |
| Weight | 250 g each |
| Eating | It gives back a little Health eaten raw, until you move or are hurt |
| Effects | None |
| Plant | Leaves over a swollen root, about 40 cm tall and 28 cm across |
| Growth | Fast: full grown in 2 days of game time |
| Picking | One to three when full grown, more with Foraging and Crops |
| After picking | Dug up: nothing grows there for a whole growth, then it starts again from a shoot |
